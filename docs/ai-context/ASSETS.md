## 3. Fonts are NOT files

Despite `assets/fonts/` existing, **no font files are bundled**. Typefaces come from npm packages, loaded in [theme/fonts.ts](../../theme/fonts.ts) via `useAppFonts()`:

- `@expo-google-fonts/anek-devanagari` — Devanagari (Nepali site names)
- `@expo-google-fonts/ibm-plex-sans` — UI text
- `@expo-google-fonts/ibm-plex-mono` — measurements (`MetaRow` defaults to mono)

`useAppFonts()` returns `{ ready }`, which gates the splash screen in [app/_layout.tsx](../../app/_layout.tsx). **To add a typeface, add the package** — do not drop a `.ttf` into `assets/fonts/`.

## 4. How assets are referenced

| Mechanism | Used for | Example |
|---|---|---|
| `app.json` config | Icons, splash, favicon, notification icon | `"icon": "./assets/icon.png"` |
| Data-file registry | Audio, plates | [data/audio.ts](../../data/audio.ts), [data/plates.ts](../../data/plates.ts) |
| Direct `require()` | Component images | Monk frames |
| `expo-asset` | The ONNX model | [services/ai/onnx.ts](../../services/ai/onnx.ts) |

**The registry pattern matters:** audio and plates are referenced through data modules, not scattered `require()` calls. Add new ones to the registry so content stays swappable — consistent with the `@/data` barrel rule.

## 5. Metro asset extensions

```js
config.resolver.assetExts.push('wasm', 'opus', 'onnx', 'pte');
```

| Ext | For |
|---|---|
| `wasm` | expo-sqlite web build |
| `opus` | Narration audio |
| `onnx` | Damage detector model |
| `pte` | Reserved — possible ExecuTorch migration |

**Adding a new binary type without adding its extension here causes a bundling failure or a runtime parse error.**

## 6. Adding an asset — checklist

| Type | Steps |
|---|---|
| Narration audio | Add `<site-id>.<lang>.opus` → register in [data/audio.ts](../../data/audio.ts) → verify site id matches `data/generated/sites.ts` |
| Historical plate | Add to `assets/plates/` → register in `seed/plates.json` + [data/plates.ts](../../data/plates.ts) → **declare its evidence tier** → **record licensing in [LICENCES.md](../../LICENCES.md)** → `npm run gen && npm run validate` |
| Component image | Add → `require()` it |
| Model | Add → confirm extension is in `assetExts` → check binary size impact |
| Icon/splash | Replace file → update `app.json` if the name changed → **rebuild** (native) |

**Always:** use the correct site id (from `data/generated/sites.ts`, **not** the dead `data/demo/sites.ts`), and consider binary size.
