# Sākṣī brand kit

*Sākṣī* means **witness**. The mark is an eye drawn from Lumbini itself: the upper lid is a Himalayan ridge, the iris is the morning sun in sayapatri marigold, and the lower lid is the lotus of the Buddha's first steps in the jade of the Puskarini pond.

`saksi-brand-board.png` shows the whole system on one page. Colour, type and voice are defined in [DESIGN.md](../DESIGN.md).

## Rules

- **Clear space:** keep at least the width of the sun's radius around the mark on every side.
- **Minimum size:** 24 px for the mark, 96 px wide for the lockup.
- **Colour:** use only the supplied versions. Don't recolour, rotate, outline or add effects to the mark.
- **Grounds:** use the light version on mist or white, the dark version on dusk, and the on-jade version on jade. On a photograph, place it on a solid tile.
- **Name:** in a logo position, the macron and dot below are part of the name. Never write `Saksi` or `Sakshi` there. Plain `saksi` is fine in code, URLs and file names.

## Regenerating

Everything is generated by one script, which also refreshes the app icons in `assets/`, the feature graphic and the website's icon and preview image. Wordmarks are real outlines shaped through HarfBuzz, so the `क्ष` conjunct is the true ligature. Rendering needs Google Chrome.

```sh
python3 -m venv .venv && .venv/bin/pip install fonttools uharfbuzz
.venv/bin/python tools/brand/brand.py
```
