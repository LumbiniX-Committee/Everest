# Before you walk on

Source: 09-PITCH-AND-DEMO §7. Run this list before every rehearsal and before
the real thing.

- [ ] Demo device charged, screen mirroring tested **on the actual venue projector**
- [ ] All permissions pre-granted (camera, location, motion)
- [ ] Backup video cued and ready to play in one tap
- [ ] Deck open on a second device
- [ ] `LICENCES.md` open in a browser tab
- [ ] Eval numbers table open
- [ ] Git log open (`git log --oneline` — the 48-hour evidence)
- [ ] Notifications off, do-not-disturb on
- [ ] One person talks, one drives, handoff rehearsed
- [ ] Whoever is most awake gives the pitch

## Rehearsal targets

- [ ] **Three timed runs.** Most teams rehearse zero times, and it shows within
      twenty seconds. This is the single most reliable predictor of outcome
      (10-REVIEW §5).
- [ ] Total under six minutes with the applause pause at 1:40 left in.
- [ ] The three memorised sentences land without notes (see demo-script.md).
- [ ] Debug timers flipped back OFF for any run that isn't demoing the ritual.
- [ ] Every failure drill practised once (see failure-drills.md).

## Hard freezes (do not let these slip)

- [ ] **Hour 30: feature freeze.** After this, only rehearsal and insurance.
- [ ] **Hour 42: demo video recorded.** The backup that makes a crash a non-event.
- [ ] **Hour 44: tools down.** No new dependencies, no refactors.
